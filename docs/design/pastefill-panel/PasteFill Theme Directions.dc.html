Turn 5 · 4c refined
4c, borders back, yellow out
Paper is now a neutral grey with only a trace of warmth — no cream, no ochre fills. Every card has a hairline border again. What is doing the work here
Radii are concentric: 14 → 10 → 7, each step equal to the outer radius minus the padding, so no curve looks pinched inside another.
Only one saturated colour appears per state, at small size. The row itself is never coloured in 5b; a 3px rule carries it.
Borders sit close to the fill they separate — #E7E7E4 on #FCFCFB — so structure is felt, not seen.
Type: 500 is the heaviest weight used, tracking tightens as size grows, and the muted grey is a true neutral so it reads as quieter, not colder.
Everything lands on 4px: 12 padding, 16 gaps, 8 inner gaps, 6px markers.
Turn 4 · tinted paper, tightened
PasteFill — warm paper, one notch tighter
Renamed to PasteFill throughout. No pure white anywhere: the panel sits on a warm tinted paper and the rows are a shade lighter than it, so cards separate by tone rather than by outline. Row padding comes down from turn 3's 16–18px to 13–14px while the gap between rows stays generous — tighter cards, same air between them. Three tint temperatures.

Turn 1 · colour + type directions
Three themes for the panel
Each one is a full token set — page, surface, text, rule, accent, and the four status colours the review rows depend on — shown as swatches, a type specimen, and a live 380px slice of the panel. Semantic colours are tuned per direction so extracted / inferred / missing stay separable at 10.5px on a light background. Reference 1a, 1b, 1c in chat.

The coolest and most neutral of the three. Geist is a grotesque built for interfaces — tight numerals, unambiguous 1/l/I, which matters for NRIC and policy numbers. Accent is a desaturated clinical blue that never competes with the insurer's page.
